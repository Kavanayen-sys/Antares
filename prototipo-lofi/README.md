# Prototipo del Sistema (CET1 - CL1)

Este prototipo tiene dos partes separadas para mostrar como usa el sistema cada tipo de usuario:

## 1. cooperativista.html (Movil)
Muestra la pantalla que usaria la cuadrilla en la calle desde el celular.

Que hace y que tiene:
- Muestra los datos de la cuadrilla (chofer, peon, camion asignado y la ruta).
- Lista de los contenedores a vaciar en orden.
- Boton en cada contenedor para marcar cuando ya fue vaciado.
- Formulario abajo para avisar a la base si un contenedor esta roto, quemado o desbordado.
- Enlace para ir a la vista de administrativo.

## 2. administrativo.html (Computadora)
Muestra la pantalla que usa el administrativo en la oficina desde la computadora.

Que hace y que tiene:
- Tabla con las cuadrillas que estan trabajando y que camion tienen.
- Tabla con los contenedores que estan en la ruta y su estado.
- Tabla de incidencias con los problemas que reportaron los vecinos o las cuadrillas, con boton para despachar auxilio.
- Formulario para asignar cuadrilla a camion y ruta.
- Enlace para ir a la vista de cooperativista.

## 3. index.html
Pagina simple para elegir si abrir cooperativista.html o administrativo.html.
